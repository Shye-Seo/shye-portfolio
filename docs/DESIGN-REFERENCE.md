# chatis.kr 레퍼런스 분석 노트

> 이 사이트(`shye-portfolio`)의 디자인 기준을 잡기 위해 2026-11-21에
> `https://chatis.kr`을 브라우저로 직접 열어 스크롤·섹션 전환·타이포그래피·컬러를
> 확인하고, 배포된 CSS(`build/assets/app-*.css`)에서 실제 토큰 값을 읽어 정리한 기록입니다.

## 1. 구조 (섹션 순서)

1. 고정 내비게이션 — 로고 · 5개 링크 · 노란 CTA 버튼
2. 히어로 — 좌: 배지 + 2줄 대제목 + 설명 + CTA 2개 / 우: 누적 지표 카드
3. 진단(선택형 진입) — "지금 가장 해결하고 싶은 고민은?" 4개 선택 카드
4. 탭형 추천 — 탭 5개 + 세부 상황 칩 + 좌측 요약 카드 / 우측 번호 리스트
5. 기능 미리보기 — 텍스트 ↔ 목업이 좌우로 번갈아 배치되는 2열 행 6개
6. 지표 + 파트너 로고 벽 (40,000+ / 1,400억+)
7. 브랜드 소개 + 3개 역량 카드
8. 스토리(블로그) 카드 4개
9. 앱 라인업 — 3열 카드 그리드(배지 + 태그 칩 + 제목 + 설명 + 알아보기)
10. FAQ — 흰 카드 아코디언 9개
11. 다크 라운드 카드 CTA + 푸터

## 2. 스크롤 · 인터랙션

- 섹션 등장: `IntersectionObserver`로 `.reveal` → `.visible` 클래스 토글.
  - `.reveal { opacity: 0; transform: translateY(1.5rem); transition: opacity .6s cubic-bezier(.22,1,.36,1), transform .6s cubic-bezier(.22,1,.36,1); }`
  - `.reveal.visible { opacity: 1; transform: translateY(0); }`
  - 즉 "한 번 떠오르고 끝"이 아니라 이동 거리 24px·0.6초의 짧은 페이드업.
- 앵커 이동은 `scroll-behavior: smooth`와 `scroll-margin-top`으로 고정 헤더 높이를 보정.
- 고정 헤더는 스크롤 후 배경이 살짝 차오르는 방식(블러·반투명).
- 목업·카드에는 hover 시 2~5px 정도의 translate와 그림자 강조만 사용.
- 탭·카드 선택 상태는 **테두리 색 + 연한 파란 배경 + 채워진 원형 화살표**로 표시.
- 아코디언은 카드형 + 원형 아이콘 회전. 열린 항목만 테두리가 푸르게 변함.

## 3. 타이포그래피

| 요소 | 값 |
| --- | --- |
| 폰트 | `Paperlogy` (눈누 배포, weights 400·500·600·700·800) |
| H1 | 60px / weight 800 / line-height 66px(1.1) / letter-spacing -1.5px |
| 본문 | 16px 내외, line-height 1.7~1.8, 색 `#3a3835` |
| 킥커 | 12~13px, 파란색, 앞에 짧은 대시(—)를 붙인 라벨 |
| 강조어 | 파란색(`#2563eb`) + 노란 형광 밑줄 |
| 제목 색 | `#1a1917` (거의 검정) |

- 제목은 2줄로 끊고, 둘째 줄의 핵심 단어만 색을 바꿔 시선을 고정.
- 숫자 지표는 40~60px, 굵기 800, 자간 -0.04em.

## 4. 컬러 시스템 (실제 CSS 변수)

```
--ct-bg:#f9f8f6   --ct-surface:#f2f1ee   --ct-surface-warm:#f5f3f0
--ct-border:#d8d5cf   --ct-border-light:#e8e6e1
--ct-text:#3a3835   --ct-heading:#1a1917   --ct-muted:#6b6860
--ct-accent:#2563eb   --ct-accent-light:#eff6ff   --ct-accent-hover:#1d4ed8
--ct-dark:#16140f   --ct-dark-surface:#211f1a   --ct-dark-text:#d4d1c9
--section-y: clamp(5rem, 8vw, 8rem)
```

- 배경은 흰색이 아니라 **따뜻한 회백색 3단**(`#f9f8f6` / `#f2f1ee` / `#edecea`)을 번갈아 씀.
- 강조색은 파랑 하나만. CTA만 노랑(`#ffd60a`)으로 분리.
- 다크 섹션은 순검정이 아니라 갈색 기운이 있는 `#16140f`.

## 5. 레이아웃 · 밀도

- 컨테이너 최대 1200px, 좌우 패딩 24~40px.
- 섹션 상하 여백 `clamp(5rem, 8vw, 8rem)` → 섹션 사이 호흡이 매우 넓음.
- 카드 radius 12px(작은 요소) / 16~24px(카드) / 999px(칩·버튼).
- 그림자는 거의 쓰지 않고 `1px` 헤어라인 테두리로 카드를 구분.
- 3열 카드·2열 교차 행·중앙 정렬 아코디언을 반복해 리듬을 만듦.

## 6. 이 사이트에 적용한 것 / 다르게 한 것

적용:
- 위 토큰을 거의 그대로 옮겨 `src/styles/site.css`의 `:root`에 정의.
- `.reveal` · `scroll-margin-top` · 고정 내비게이션 · 2열 교차 행 · 카드형 아코디언.
- 킥커 대시, 파란 강조어 + 노란 밑줄, 지표 카드, 다크 라운드 CTA.

다르게 한 것:
- 카피 톤: 채티스는 고객(쇼핑몰 대표)에게 말 거는 반말체. 여기서는 **채용 담당자에게 근거를 보여주는 존댓말**로 바꿈.
- 로고 벽 대신 기술 스택 마퀴. 파트너 로고가 없기 때문.
- 미리보기 목업은 직접 그린 UI가 아니라 **실제 라이브 데모 화면 캡처**(Playwright)를 넣어 증거로 씀.
- "1분 진단"은 쇼핑몰 고민 선택 대신 **포지션 선택 → 근거 매칭**으로 바꿈.
- 과장된 수사 대신 각 프로젝트에 "검증 범위(미검증 항목)"를 명시.
